CHAPTER 7 — VIDEO PROCESSING FLOW
====================================

This chapter builds the VideoProcessor — the code that actually processes
uploaded videos (extracts metadata and generates a thumbnail). It plugs into
the worker pool from Chapter 6.


THE COMPLETE PROCESSING PIPELINE
=================================

┌─────────────────────────────────────────────────────────────────────────┐
│  Starting point: a message is sitting in SQS from the upload           │
│  (Chapters 3-5 handled this: file → S3, job → DynamoDB, ID → SQS)     │

         │
         ▼

┌─────────────────────────────────────────────────────────────────────────┐

                                  │

│  STEP 1: Fetch job from DynamoDB                                        │

│  job, err := p.store.Get(ctx, msg.JobID)                                │

┌─────────────────────────────────────────────────────────────────────────┐
│  VideoProcessor.Process() — video.go line 123                           │
│  This is where the actual video processing happens                      │
│                                                                         │
│  STEP A: Create temp directory                                          │
│  ─────────────────────────────                                          │
│  tmpDir := os.MkdirTemp("", "mediaforge-video-*")                       │
│  → creates something like /tmp/mediaforge-video-384729/                 │
│  → defer os.RemoveAll(tmpDir) ensures cleanup when done                 │
│                                                                         │
│  STEP B: Download video from S3                                         │
│  ──────────────────────────────                                         │
│  p.downloadToFile(ctx, job, videoPath)                                  │
│  → builds key: "originals/669d2bf2-...mp4"                             │
│  → calls p.storage.Download(ctx, key)                                   │
│  → S3/LocalStack streams the file bytes                                 │
│  → writes to /tmp/mediaforge-video-384729/input.mp4                     │
│                                                                         │
│  STEP C: Extract metadata (run ffprobe)                                 │
│  ──────────────────────────────────────                                 │
│  p.extractMetadata(ctx, videoPath)                                      │
│  → runs: ffprobe -v quiet -print_format json -show_format               │
│          -show_streams /tmp/.../input.mp4                               │
│  → ffprobe reads the video and outputs JSON                             │
│  → json.Unmarshal parses it into a Go struct                            │
│  → extracts: width, height, codec, duration, file size                  │
│  → returns *models.Metadata                                             │
│                                                                         │
│  STEP D: Extract thumbnail (run ffmpeg)                                 │
│  ──────────────────────────────────────                                 │
│  p.extractThumbnail(ctx, videoPath, thumbnailPath)                      │
│  → runs: ffmpeg -i /tmp/.../input.mp4 -ss 00:00:01 -vframes 1          │
│          -q:v 2 -y /tmp/.../thumbnail.jpg                              │
│  → ffmpeg seeks to 1 second into the video                              │
│  → grabs that single frame                                              │
│  → saves it as a JPEG in the temp directory                             │
│                                                                         │
│  STEP E: Upload thumbnail to S3                                         │
│  ──────────────────────────────                                         │
│  thumbnailKey = "thumbnails/669d2bf2-...jpg"                            │
│  p.storage.Upload(ctx, thumbnailKey, thumbnailFile, "image/jpeg")       │
│  → sends thumbnail bytes to S3/LocalStack                               │
│  → it's now stored alongside the original video                         │
│                                                                         │
│  STEP F: Get presigned URL for thumbnail                                │
│  ────────────────────────────────────────                                │
│  thumbnailURL := p.storage.GetURL(ctx, thumbnailKey)                    │
│  → generates a temporary download URL for the thumbnail                 │
│                                                                         │
│  STEP G: Return results                                                 │
│  ──────────────────                                                     │
│  return &ProcessResult{                                                 │
│      ThumbnailURL: "http://localhost:4566/.../thumbnails/669d.jpg",     │
│      Metadata: {Width:1920, Height:1080, Duration:120.5, ...},          │
│  }                                                                      │
│  → goes back to processMessage() which saves it to DynamoDB (Step 5)   │
│                                                                         │
│  (temp directory is automatically deleted by defer os.RemoveAll)        │
└─────────────────────────────────────────────────────────────────────────┘

DYNAMODB UPDATES THROUGHOUT THE LIFECYCLE
==========================================

│ When                     │ Who                │ What changes in DynamoDB     │
│──────────────────────────│────────────────────│──────────────────────────────│
│ Upload (Ch 3-4)          │ API handler        │ Job created, status=pending  │
│ Worker picks up job      │ processMessage()   │ status → "processing"        │
│ Processing fails         │ processMessage()   │ status → "failed", error set │
│ Processing succeeds      │ processMessage()   │ status → "complete",         │
│                          │                    │ thumbnail_url set,           │
│                          │                    │ metadata set                 │

WHAT HAPPENS IF PROCESSING FAILS?
===================================

┌─────────────────────────────────────────────────────────────────────────┐
│  1. processor.Process() returns an error                                │
│                                                                         │
│  2. processMessage() catches it:                                        │
│     job.Status = "failed"                                               │
│     job.Error = "running ffprobe: exec: ffprobe not found"              │
│     p.store.Update(ctx, job)    → DynamoDB updated with error           │
│                                                                         │
│  3. Message is NOT deleted from SQS                                     │
│     → but since we already set status to "failed", even if SQS         │
│       redelivers, the job is marked done                                │
│                                                                         │
│  4. GET /api/v1/jobs/669d2bf2 would show:                               │
│     {"status":"failed","error":"running ffprobe: exec: not found"}      │
└─────────────────────────────────────────────────────────────────────────┘
