┌────────────────────────────────────────────────────────────────────────┐
│  POST /api/v1/upload                                                    │
│                                                                         │
│  Purpose: Upload a media file for processing                            │
│  Content-Type: multipart/form-data                                      │
│  Max file size: 100MB                                                   │
│                                                                         │
│  Form fields:                                                           │
│    file (required) — the image or video file                            │
│                                                                         │
│  Supported formats:                                                     │
│    Video: .mp4, .mov, .avi, .mkv, .webm                                │
│    Image: .jpg, .jpeg, .png, .gif, .webp                               │
│                                                                         │
│  What happens:                                                          │
│    1. File uploaded to S3                                                │
│    2. Job record created in DynamoDB (status: pending)                  │
│    3. Job ID pushed to SQS for async processing                         │
│    4. Response returned immediately (does NOT wait for processing)      │
│                                                                         │
│  Response (202 Accepted):                                               │
│  {                                                                      │
│      "job_id": "9e4edd29-3b88-4cdc-a250-6dc50e52c4df",                 │
│      "status": "pending",                                               │
│      "message": "file accepted for processing"                          │
│  }                                                                      │
│                                                                         │
│  Errors:                                                                │
│    400 — file too large, invalid form data, missing file, bad format   │
│    500 — S3 upload failed, DynamoDB save failed, SQS send failed       │
│                                                                         │
│  Example:                                                               │
│    curl -X POST http://localhost:8080/api/v1/upload \                   │

JOB STATUSES
==============

A job moves through these states:

    pending → processing → complete
                        ↘ failed

│ Status     │ Meaning                                               │
│────────────│───────────────────────────────────────────────────────│
│ pending    │ File uploaded, waiting for a worker to pick it up     │
│ processing │ A worker is currently processing the file             │
│ complete   │ Done — metadata extracted, thumbnail generated        │
│ failed     │ Something went wrong — check the "error" field        │


ERROR RESPONSE FORMAT
======================

All errors return:
{
    "error": "human-readable message",
    "code": 400
}


MIDDLEWARE
===========

Every request passes through (in order):
  1. RequestID — stamps request with unique ID for tracing
  2. RealIP — extracts real client IP behind proxies
  3. Logger — logs method, URL, status code, and duration
  4. Recoverer — catches panics, returns 500 instead of crashing
  5. CORS — allows cross-origin requests from browsers


TYPICAL USAGE FLOW
===================

1. Upload:
   curl -X POST http://localhost:8080/api/v1/upload -F 'file=@video.mp4'
   → get back job_id

2. Check status (poll until complete):
   curl http://localhost:8080/api/v1/jobs/{job_id}
   → status goes from "pending" → "processing" → "complete"

3. Once complete:
   → thumbnail_url points to the generated thumbnail
   → metadata contains resolution, duration, codec, file size
   → original_url points to the uploaded file


RUNNING THE SERVER
===================

# Start LocalStack (S3 + DynamoDB + SQS)
make localstack

# Start the server (API + workers)
make dev

Server runs on http://localhost:8080
LocalStack runs on http://localhost:4566
